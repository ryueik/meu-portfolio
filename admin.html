Gestão de Projetos

Adicione, edite e remova projetos. As mudanças são salvas no GitHub e aparecem no portfólio.

Conexão com GitHub

Configure o token e o repositório onde os projetos serão salvos.

Como obter um token:
  1. Acesse GitHub → Settings → Developer settings → Fine-grained tokens
  2. Clique em Generate new token
  3. Em Repository access, selecione apenas o repositório do portfólio
  4. Em Permissions → Repository permissions → Contents, marque Read and write
  5. Gere o token e cole no campo abaixo
O token fica salvo apenas no seu navegador (localStorage).
